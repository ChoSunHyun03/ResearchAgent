# 평가용 예제

STEP 4에서 평가 기준을 준비합니다. 모델 평가 실행기는 STEP 14 범위입니다.

- `job_analysis_cases.json`: 직접 작성한 가상 채용공고 네 개와 사람이 정리한 기대 정보.
- `backend/tests/fixtures/search_cases.json`: 외부 검색 없이 정제 결과를 확인하는 고정 예제 네 개.
- 가상 회사 이름과 example.com URL은 실제 기업 정보나 검색 품질을 의미하지 않습니다.

## 비교 기준

공고 분석은 회사·직무 식별, 업무·필수·우대 분류, 없는 정보의 빈 값 처리,
원문에 없는 사실 추가 여부를 평가합니다. 키워드와 문장의 표현은 모델마다 달라질 수 있으므로
전체 JSON 문자열 일치로 모델 품질을 판정하지 않습니다.

계획은 회사·직무 유지, 5~7개 항목, 직무별 조사 초점, 실제 검색 가능성,
의미 중복과 근거 없는 회사 사실의 유무를 검토합니다. `planner_focus`는 참고 기준이며
정확한 단어 일치가 필수 조건은 아닙니다.

검색 정제는 URL별 중복 제거, 의미 있는 URL 값 보존, 잘못된 항목 제외,
원래 순위와 최대 개수 유지를 자동 검증합니다. 이는 검색 관련성 평가와 구분합니다.

추후 모델 비교 시 같은 입력과 설정, 모델·프롬프트 버전, 실행 시각,
성공률·응답시간·사용량을 기록합니다. 학습용 데이터와 평가용 데이터는 분리합니다.
현재 네 공고는 작은 점검용 예제이며 모델의 일반적 성능을 대표하지 않습니다.
